Built in a one-week sprint by a team of four at Dev Academy Aotearoa, Ngahuru 2026 cohort.

## Why we built it

Coming out of a bootcamp, the hardest part isn't learning to code — it's finding
something real to build next. We wanted a place where developers could find
open-source projects worth contributing to, filtered by the languages and topics
they actually care about.

Kiwicom pulls live project data from the GitHub API, lets you browse and filter
by language, topic and type, and uses AI to generate plain-English summaries of
project READMEs so you can tell at a glance whether a project is worth your time.
Users log in with GitHub through Supabase, bookmark projects, manage their own
listings, and build a developer profile.

## Features

- Browse projects in a card grid with infinite scroll
- Filter by language, topic, type and open-source status
- Full-text search with debounced input
- Bookmark projects to revisit later
